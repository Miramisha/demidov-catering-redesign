# Demidov Catering — Frontend Redesign Concept

A modern, responsive frontend concept for the Demidov Catering website. The project preserves the company’s public information while presenting it through a premium emerald-and-gold visual system.

## Highlights

- Responsive desktop and mobile layouts
- Accessible semantic structure
- Motion with reduced-motion support
- Modern service, project, and contact sections
- Frontend-only demonstration form

## Stack

React 19, TypeScript, Vinext, CSS, Lucide icons.
